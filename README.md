# Comparely — AI-Assisted Competitive Analysis Platform

## Overview

Comparely is a full-stack competitive analysis application developed collaboratively during Fullstack Academy's Software Engineering program in August 2023.

The project was designed to collect external company data and leverage artificial intelligence to assist users in analyzing businesses and their competitors.

## Project Information

- **Project type:** Collaborative educational project
- **Developed:** August 2023
- **Program:** Fullstack Academy
- **Status:** Historical educational project

## Project Objectives

- Collect external company and competitor data.
- Integrate third-party APIs for information retrieval.
- Explore automated web data collection.
- Utilize artificial intelligence to assist with competitive analysis.
- Present collected information through a web application.
